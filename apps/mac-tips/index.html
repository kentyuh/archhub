先认识键盘

最重要的一节

从 Windows 过来，最关键的一个变化：Mac 用 ⌘ Command 代替了 Ctrl。绝大部分"复制粘贴"类操作都按 Command。

⌘ Command

核心修饰键，相当于 Windows 的 Ctrl。位置在空格键两侧。

⌥ Option / Alt

扩展功能键，常用来调出隐藏选项，比如另存为、特殊符号。

⌃ Control

传统控制键，配合触控板点按相当于"右键"。

⇧ Shift / ⇪ Caps Lock

大写锁定键轻按一下可切换中英文输入法（需系统设置里开启）。

小技巧：按住 ⌥ Option 再点菜单栏图标，常能打开隐藏菜单；按住它拖动窗口，可以绕过"吸附"直接自由移动。

触控板手势

Mac 的灵魂
  • 单指移动光标；轻点一下等于单击。
  • 双指上下滑动滚动页面；双指轻点 = 鼠标右键（也可双指按触控板下角）。
  • 双指捏合 / 张开缩放页面或图片。
  • 三指左右滑切换已打开的应用；三指上下滑在应用窗口和桌面间移动。
  • 四指上滑打开调度中心，看到所有窗口；四指左右滑切换不同桌面。
  • 四指张开显示桌面（Launchpad 用拇指+三指捏合）。
去「系统设置 → 触控板」按自己的习惯调灵敏度，还能预览每个手势的效果。

聚焦搜索 Spotlight

效率神器

按 ⌘空格 呼出搜索框，它不只是找文件：

  • 输入应用名直接打开应用，比如"微信""浏览器"。
  • 输入文件名，快速定位全盘文档。
  • 直接算算术：25*8、查汇率、换算单位、查单词翻译。
  • 用方向键选中结果后按 Return 打开。

访达 Finder 与文件管理

像"资源管理器"
  • 空格键快速预览：选中文件按空格，不打开也能看内容、看图、看 PDF，再按空格关闭。
  • 前往文件夹：⌘⇧G，粘贴路径直接跳转。
  • 侧边栏收藏：把常用文件夹拖到左侧，一键到达。
  • 文件标签：右键文件可加颜色标签，按颜色快速分类筛选。
  • 新建文件夹：⌘⇧N；重命名：选中后按 Return。
  • 显示隐藏文件：⌘⇧.（再按一次隐藏）。

窗口与桌面管理

多任务不慌
  • 分屏：按住窗口左上角绿色按钮，或把窗口拖到屏幕左/右边缘，即可半屏并排。
  • 调度中心：F3 或四指上滑，一览所有窗口。
  • 多个桌面：在调度中心点右上角「+」新建桌面，可把不同任务分到不同桌面，四指左右滑动切换。
  • 台前调度 Stage Manager：系统设置 → 控制中心里开启，自动整理窗口、减少混乱。
  • 最小化：⌘M；恢复最小化的窗口可从程序坞 Dock 点击应用。

给新手的额外提示

少踩坑

软件装哪里？

从 App Store 下载，或官网下载 .dmg / .pkg 安装包。谨慎安装来路不明的软件。

怎么卸载 App？

大部分 App 直接拖到废纸篓即可；从 App Store 装的用 Launchpad 长按图标删除。

找到"控制面板"

Mac 叫「系统设置」，在 Dock 齿轮图标或 苹果菜单 → 系统设置里打开。

电池保养

开启「优化电池充电」；长期插电办公建议偶尔用到 20%~80% 之间循环。

切换输入法

用 ⌃空格 切换输入法；拼音状态下直接按 ⇧ Shift 切中英文。详见第 9 节。

文件备份

重要文件开启 iCloud 云盘或定期用「时间机器 Time Machine」外接硬盘备份。

官方"使用手册"最权威：打开「帮助 → Mac 使用手册」，或访问 support.apple.com，遇到具体问题随时查。

切换输入法（详细版）

每天都要用

输入中文前，先确认已经添加好中文输入法：苹果菜单 → 系统设置 → 键盘 → 文本输入 → 编辑 → 点 + 添加「简体中文 - 拼音」。

想做什么怎么操作
中英文来回切（最常用）⌃空格
中文拼音内部切中 / 英直接按 ⇧ Shift
在多个输入法之间逐个切换⌃⌥空格
用大小写键切换⇪ Caps Lock（需先在设置里开启）
鼠标点选点菜单栏右上角的输入法图标（"中"/"英"/国旗）
避坑提醒：从 Windows 过来常按的 ⌘空格，在 Mac 上默认是「聚焦搜索」，不是切输入法。记住 Mac 切输入法用 ⌃空格（Control + 空格）。

开启 Caps Lock 切换：系统设置 → 键盘 → 文本输入 → 编辑 → 打开「使用大写锁定键在大写和小写 / 拉丁与非拉丁输入源之间切换」。开启后按一下大写键即可中英互切。

让每个 App 记住自己的输入法：在同一页勾选「自动切换到文稿的输入源」，这样切到不同应用会自动用回该应用上次用的语言，省去频繁手动切换。

Mac 上的 AI 编程工具（Vibe Coding）

2026 年底版

"Vibe coding" 就是用自然语言描述需求、让 AI 写代码的开发方式。下面按你的角色（技术架构负责人）排序，而不是按榜单排名——工具迭代很快，结论以 2026 年 11 月实测为准。

工具定位 / 适合场景
Qoder
阿里 · 主力推荐		智能体自主开发工作台，不是"中国版 Cursor"。Repo Wiki 自动扫全仓生成架构文档/知识图谱，适合接手祖传代码；Quest 模式先出 Spec 方案、你确认再动手；交付时自动生成 Dockerfile / CI / Helm。强项是大型后端、存量系统重构。短板：前端/多模态一般，学习成本偏高。
CodeBuddy
腾讯 · 生态协同		与你正在用的 WorkBuddy 同源，MCP 生态是主打，配置零门槛；CodeBuddy Code 兼容 Claude Code 的 Skills，积累可复用；免费起步，Pro 约 $12/月。短板：复杂多文件协同偏弱，成熟度仍在提升。
Claude Code
终端 · 能力上限		命令行 Agent，Plan Mode 先规划再落地，跨文件重构成功率最高（SWE-bench 领先）。适合大型重构、架构级任务。短板：终端形态有门槛、成本最高（约 $100-200/月），无免费档。
TRAE
字节 · 轻量备选		开箱即用、国内直连、内置国产模型、中文理解好、基础版免费。适合快速原型、前端/小程序、零预算起步。短板：超大工程和复杂后端能力有限。
给你的使用顺序：日常先 CodeBuddy（省心、和现有工具链合得来）→ 接手大型存量项目或做架构重构时用 Qoder → 需要啃最硬的骨头再上 Claude Code → 做快速前端原型用 TRAE。

两个避坑提醒：① 看到推荐 Windsurf 的攻略是过时的——它 2025 年被 Cognition 收购，2026 年 6 月已改名 Devin Desktop。② Cursor 从 2025 年 6 月起改为 credit 计费，"Auto 无限"实际是 fair-use，重度使用会跑光额度。

一句实话：Vibe coding 加速好的判断，但不产生好的判断。真正值钱的是任务拆解和架构设计——这部分工具替不了你。
